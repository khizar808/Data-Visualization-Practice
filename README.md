# 📊 Data Visualization Practice

A hands-on collection of Python notebooks focused on **data visualization and exploratory analysis** using **Matplotlib, Seaborn, and Pandas**.

This repository showcases my practical work with visualizing data, from fundamental charts to statistical and multi-variable visualizations. It reflects my learning process and provides a foundation for applying visualization techniques to real-world **Data Science and Machine Learning** problems.

## 📓 Notebooks

### Matplotlib Practice

Exploration of fundamental visualization techniques, including:

* Line, bar, and scatter plots
* Histograms, box plots, and violin plots
* Pie and doughnut charts
* Subplots and multi-series visualizations
* Plot customization, labels, markers, and styling
* Visualizing data from Pandas DataFrames and CSV files

### Seaborn Practice

Exploration of statistical and multi-variable visualization, including:

* Line, bar, and scatter plots
* `hue`, `style`, and markers
* Distribution and KDE plots
* Joint and regression plots
* Box plots and pair plots
* Built-in datasets such as `fmri` and `penguins`
* Visualization of custom CSV datasets

## 🛠️ Tech Stack

**Python · Pandas · Matplotlib · Seaborn · Jupyter Notebook**
